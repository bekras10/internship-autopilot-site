Internship Autopilot

Internship Autopilot is a personal software project that helps its owner run an internship search more efficiently. It is a single-user tool operated only by its owner. It is not a service offered to the public, and no one else can sign up for or use it.

What it does

  • Internship discovery: collects publicly posted internship listings from employer job boards and filters them against the owner's own criteria.
  • Application tracking: keeps a private record of which positions the owner has applied to, to avoid duplicate applications.
  • Gmail monitoring (read-only): reads the owner's own inbox to recognize recruiting updates such as application confirmations, assessments, interviews, and decisions. It never sends, deletes, or modifies email.
  • Google Sheets updates: keeps the owner's personal application-tracker spreadsheet up to date.

Google user data

The tool accesses only the owner's own Google account, with the owner's consent. Read the Privacy Policy for details on what data is accessed, how it is used, and how access can be revoked.
